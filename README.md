# CareerOS – AI-Powered Career Management Platform

<escape>🚧</escape> **Project Status: Currently Under Development**

CareerOS is an AI-powered career management platform designed to help students and job seekers organize their career journey in one place.

The platform aims to simplify job application tracking, professional resume creation, and career planning through modern web technologies and AI-powered features.

This project is currently under active development. New features, improvements, and integrations are being added gradually.

## 🚀 Project Features

The following features have been implemented or are currently being developed.

### 1. User Authentication
- User Registration
- User Login and Logout
- JWT-based Authentication
- Protected Routes

### 2. Dashboard
- Dashboard interface
- Navigation between platform modules
- Career management overview

### 3. My Profile
- User profile management
- Personal information management

### 4. AI Resume Builder
- AI-powered resume generation using Gemini API
- Resume editing and customization
- Multiple resume templates
- Save and manage resumes
- PDF resume download
- Autofill resume details from user profile

### 5. Job Tracker
- Add job applications
- Edit and delete applications
- Track application status
- Manage interview dates
- Search and filter applications
- View application statistics

## ⚙️ Installation and Setup

### Prerequisites
- Node.js and npm
- MongoDB Atlas account
- Google Gemini API key

### 1. Clone the Repository

```bash
git clone https://github.com/SWETAJADON/CareerOS.git
```

### 2. Navigate to the Project

```bash
cd CareerOS
```

### 3. Install Frontend Dependencies

```bash
npm install
```

### 4. Install Backend Dependencies

```bash
cd backend
npm install
```

### 5. Configure Environment Variables

Create a `.env` file inside the backend folder and configure the required environment variables according to your backend code.

These may include:
- MongoDB connection string
- JWT secret
- Gemini API key
- Server port

**Important:** Never upload your `.env` file or expose API keys and database credentials publicly.

### 6. Start the Backend

```bash
node server.js
```

### 7. Start the Frontend

Open another terminal in the main project folder:

```bash
npm run dev
```

Open the local URL displayed in your terminal.
